# dominoshki
Размещение доминошки
Яндекс: Тренировки: от алгоритмов к стажировке. Соревнование 1
Условие задачи:
Дано клетчатое поле размером n×m. Некоторые клетки поля заняты. Определите, сколькими способами можно положить доминошку размером 2×1 (её можно также повернуть на 90 градусов), так, чтобы ни одна клетка доминошки не располагалась в занятой клетке.

Ведущий тренинга предлагает решение с последовательным перебором: сначала обрабатываются горизонтальные расположения доминошек (по строкам), затем — вертикальные (по столбцам). 
<img width="812" height="510" alt="image" src="https://github.com/user-attachments/assets/63311d98-439c-4b58-b046-ce29edaf63d5" />
Данный подход, на мой взгляд, неоптимален по двум причинам:

1. Требуется хранить в памяти всю матрицу целиком, что может привести к значительным затратам оперативной памяти при больших объёмах входных данных.
2. Выполняются два отдельных прохода по данным (по горизонтали и вертикали), что увеличивает общее число итераций.

Более эффективный подход заключается в обработке только двух соседних горизонтальных строк одновременно. Далее представлена реализация такого решения
